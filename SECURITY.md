# Безопасность

Нашли уязвимость — **не пишите о ней в обращениях на GitHub и в обратной связи из программы**: и то и другое видно всем. Напишите лично:

- Telegram — https://t.me/DalniyX
- через GitHub — [закрытое сообщение об уязвимости](https://github.com/DalniyX/narrata-releases/security/advisories/new)

Исправления выходят в новой версии, программа обновляется сама — поддерживается последняя стабильная версия.

# Security

Found a vulnerability — **do not post it in GitHub issues or in the in-app feedback**: both are public. Contact us privately:

- Telegram — https://t.me/DalniyX
- on GitHub — [private vulnerability report](https://github.com/DalniyX/narrata-releases/security/advisories/new)

Fixes ship in a new version and the app updates itself — the latest stable version is supported.
