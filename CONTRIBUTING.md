# Как помочь Narrata

- 🐞 **Нашли ошибку** — в программе «Справка → Обратная связь»: к сообщению приложатся версия и система. Или [новое обращение на GitHub](https://github.com/DalniyX/narrata-releases/issues/new/choose) по шаблону.
- 💡 **Есть идея** — так же, через обратную связь или [обращение](https://github.com/DalniyX/narrata-releases/issues/new/choose). Что уже в планах — на [сайте](https://narrata.space/roadmap.html).
- 🌍 **Перевести интерфейс** — шаблон и инструкция в папке [`locales/`](https://github.com/DalniyX/narrata-releases/tree/HEAD/locales); перевод присылайте через pull request.
- 💜 **Поддержать разработку** — [Boosty](https://boosty.to/narrata/donate) · [DonationAlerts](https://dalink.to/dalniyx).

Обращения на GitHub видны всем: не прикладывайте личные данные и чужие сценарии.

Код Narrata закрыт, поэтому pull request принимаются только с переводами.

---

# Contributing to Narrata

- 🐞 **Found a bug** — use “Help → Feedback” in the app: the version and system are attached automatically. Or [open an issue on GitHub](https://github.com/DalniyX/narrata-releases/issues/new/choose) using a template.
- 💡 **Have an idea** — the same way, through feedback or [an issue](https://github.com/DalniyX/narrata-releases/issues/new/choose). What is already planned is on the [website](https://narrata.space/roadmap.html).
- 🌍 **Translate the interface** — the template and instructions are in [`locales/`](https://github.com/DalniyX/narrata-releases/tree/HEAD/locales); send the translation as a pull request.
- 💜 **Support development** — [Boosty](https://boosty.to/narrata/donate) · [DonationAlerts](https://dalink.to/dalniyx).

GitHub issues are public: do not attach personal data or other people’s scripts.

Narrata is closed-source, so pull requests are accepted for translations only.
